Title: Outlook / Email Not Working

Important:
- AI must not access user mailbox or read emails.
- Verify caller before creating ticket.
- Check if issue is client-side (Outlook) or server-side (Exchange/365).

Questions:
1. Are you using Outlook desktop app, Outlook Web (OWA), or mobile app?
2. What specific issue? (Not sending, not receiving, search not working, calendar sync, shared mailbox)
3. Any error message? (e.g., "Need password", "Disconnected", "Cannot expand folder")
4. Are you on VPN or office network?
5. Can you access Outlook Web App (outlook.office.com) from browser?

Troubleshooting:
1. If Outlook desktop: Close and reopen Outlook. Check bottom right for "Connected" status.
2. If "Need password" prompt: Enter current password. If persists, create password reset ticket.
3. If "Disconnected" / "Working Offline": Click Send/Receive → Work Offline to toggle off.
4. If search not working: Rebuild search index (File → Options → Search → Indexing Options → Advanced → Rebuild).
5. If shared mailbox missing: Restart Outlook. If still missing, create ticket for Exchange team.
6. If calendar not syncing: Check OWA calendar. If OWA works, it's client-side → reinstall Outlook.
7. If on VPN: Disconnect/reconnect VPN. Try OWA without VPN.

Action:
1. If OWA works but desktop fails → create ticket for Endpoint Support (Outlook client).
2. If OWA also fails → create ticket for Exchange / Messaging Team.
3. If verified and issue resolved → record resolution ticket.

Escalation:
Group: Service Desk (triage) → Exchange Team / Endpoint Support
Priority: Medium (High if entire department affected)
