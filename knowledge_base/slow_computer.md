Title: Slow Computer / Performance Issues

Important:
- AI must not run remote diagnostics or registry edits.
- Verify caller and asset tag if available.
- Guide through safe, reversible steps only.

Questions:
1. When did slowness start? (After update, new software, always)
2. What is slow? (Boot, apps opening, file copy, web browsing, everything)
3. Any error messages? (Low memory, high disk, high CPU)
4. Are you on VPN? (VPN can slow local resources)
5. Laptop or desktop? Docked or undocked?

Troubleshooting:
1. Restart computer (full shutdown, not sleep/hibernate). Wait 30 seconds before power on.
2. Check Task Manager (Ctrl+Shift+Esc) → Performance tab: Note CPU, Memory, Disk usage at idle.
3. Close unnecessary browser tabs/apps. Disable startup apps: Task Manager → Startup → Disable non-essential.
4. If on VPN: Disconnect VPN for local tasks. Test speed off VPN.
5. If docked: Undock → test on battery. Dock firmware/driver issue possible.
6. Run Windows Update: Settings → Update & Security → Check for updates. Install all, restart.
7. Free disk space: Settings → System → Storage → Temporary files → Delete. Keep >20% free.
8. If HDD (not SSD): Defragment not needed on SSD. Consider hardware upgrade ticket.

Action:
1. If restart + updates fixes → record resolution ticket.
2. If high CPU/disk by specific process (antivirus, indexing, Teams) → create ticket for Endpoint Support.
3. If hardware limitation (HDD, <8GB RAM, old CPU) → create Hardware Request ticket (Manager Approval).
4. If malware suspected → create ticket for Security Team (EDR scan).

Escalation:
Group: Service Desk (triage) → Endpoint Support / Hardware Team
Priority: Low (Medium if impacting business-critical work)
