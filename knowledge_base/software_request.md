Title: Software Installation / Application Request

Important:
- AI must not install software remotely or bypass approval.
- All software requests require Manager Approval ticket.
- Verify caller and check if software is in Company Portal / Intune.

Questions:
1. What software do you need? (Exact name, version if known)
2. What is the business justification? (Project, role requirement, compliance)
3. Is it available in Company Portal / Software Center?
4. Do you have local admin rights on your device?
5. Is this for a company laptop or desktop?

Troubleshooting:
1. Check Company Portal (Windows) / Self Service (Mac) / Intune Company Portal app.
2. If available there: Install self-service. No ticket needed.
3. If not in portal: Requires Software Request ticket with Manager Approval.
4. If license cost involved: Procurement approval also needed.
5. If free/open-source: Still requires Security Review ticket.

Action:
1. If in Company Portal → guide caller to install. Record resolution if successful.
2. If not in portal → create ticket: Category "Software Request", Group "Software Deployment".
3. Ticket auto-sets to "Pending Manager Approval" per policy.
4. If urgent/security tool → escalate to Security Team.

Escalation:
Group: Software Deployment / Service Desk
Priority: Low (Medium if blocking critical work)
